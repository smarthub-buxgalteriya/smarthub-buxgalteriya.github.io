# Smart.hub — лендинги курса бухгалтерии

Короткие мобильные лендинги для рекламы.

| Страница | Файл |
|---|---|
| Вариант A — «Премиум» (главная) | `index.html` |
| Старый основной | `main.html` |
| Вариант B — «Энергия» | `variant-b.html` |
| Вариант C — «Бенто» | `variant-c.html` |

Кнопки ведут в Telegram к `@smarthubmanager` с готовым сообщением «Assalomu alaykum! Buxgalteriya kursini sotib olmoqchi edim.» и кодом лендинга в конце: `#A` (главная), `#B`, `#C`, `#M` (старый основной) — по хэштегу менеджер видит, откуда заявка.

Старая ссылка `variant-a.html` перекидывает на главную.

Таймер: в конце каждого файла строка `const DEADLINE = ""`. Пусто — отсчёт до конца дня; укажите дату закрытия набора, например `"2026-12-15T23:59:00+05:00"`.
